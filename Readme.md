# Lab 1. Монитор на POSIX Threads

Реализация монитора на C++ с использованием
POSIX Threads.

## Что демонстрирует

- Поток-поставщик (`producer`) раз в секунду инициирует событие.
- Поток-потребитель (`consumer`) ждёт событие и обрабатывает его.
- Сообщения строго чередуются: `отправлено` → `обработано`.
- Ожидание события не нагружает CPU: поток спит в `pthread_cond_wait`.
- Корректное завершение: `stop` + `broadcast`, без потери событий.
- Передача несериализуемых данных — по указателю (`const void*`).
